# ddlNew 原生界面设计参考

更新日期：2026/9/29

## 适用范围

本次覆盖会员首页与底部导航。登录、AUTH、数据存储和其他业务页面不在此次重设计范围内。
构建具体页面时先读取 `pages/home.md`；该文件优先于本文件。

## 设计方向

ui-ux-pro-max 检索使用 `nature travel membership calm`，采用自然绿色、简洁排版和清晰的内容层级。
检索中的 Web 字体、CSS、营销页布局不直接移植到 iOS；原生实现使用系统字体、SF Symbols、NavigationStack 与 Dynamic Type。

## 布局与视觉

- 暖白背景、森林绿强调色、浅薄荷与沙色入口，避免大量阴影与装饰模糊。
- 4/8pt 间距体系，常用 12/16/20/24pt；保持清晰分组。
- 普通文字对比度至少 4.5:1；首页配色在 `HomeTheme.swift` 集中维护，支持深浅色。
- 视觉插画使用静态矢量山景，不把装饰当作活动照片或真实数据。

## 交互与可访问性

- 原生 Button / NavigationLink，可点击区域至少 44pt。
- 首页内的活动和俱乐部是二级导航，不占用底部 Tab。
- 保留系统返回和各 Tab 的独立导航历史，不通过 sheet 呈现主要业务页面。
- 按压改变透明度，不引入布局移动或持续动画；大字体下允许卡片纵排和文本换行。
- 图标控件提供语义名称，装饰图形从辅助功能中隐藏，状态同时使用文字表达。

## 数据边界

用户昵称从已认证会话传入；活动、俱乐部、报名等仍使用现有本机演示数据。
本次不新增活动服务接口，也不把缓存或演示数据当作用户已通过 AUTH 的依据。
