# 语音输入 UI / UX 调整

> 执行：当前会话完成局部实现与验证，独立复核增量；不提交或推送。

**目标与已确认方案：** 用户选择“按住说话、松开发送”。左侧加号保留，右侧麦克风切换语音/键盘；语音模式以整条按住区域替换文本编辑器，取消独立大面板。录音时在输入栏上方显示真实电平、时长和取消提示，上滑取消时变红。草稿与原发送链路保留。不增加试听确认步骤。

**方案取舍：** 已讨论直接按住发送与录后试听，用户选择前者。原来先展开面板再寻找小录音触点的交互被替换。

**技术：** SwiftUI 展示，现有 UIKit UIControl 跟踪手势。只改 ChatMediaComposer.swift、ChatVoiceRecordButton.swift 和专项验证。录音器、状态机、上传、SDK、权限规则不改。

**交互细节：** 录音触点覆盖中间输入栏全部区域；初始按下位置向上移动60pt进入取消状态，滑回阈值内恢复发送，水平/轻微竖向抖动不取消。按住区域布局在录音过程中固定，反馈覆盖在消息区而不移动触点。正在申请权限时显示准备状态，提前松手继续走原取消流程。保留旁白开始/结束及取消动作。
