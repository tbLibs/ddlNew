# 岩白与钴蓝 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 feature-newUI-5 将用户确认的全页面设计应用到现有 iOS 页面，保留业务行为。

**Architecture:** 保留 SwiftUI 页面、原生导航栈及全部 Store/SDK 边界。先统一已有主题和公共控件，再调整首页、活动、登录、个人中心及消息关联页面；模型、接口、持久化和权限判断不变。

**Tech Stack:** SwiftUI / UIKit / UIAdapter，iOS 16+，现有锁定依赖。

**Spec:** `Docs/design/new-ui-business-2026-10-30/DESIGN.md`，同目录 pages.json、flow-*.png 与 screens/ 为用户最新批准的业务校正版。LOGO 固定采用 D「笑着聊」，brand/mark.svg 与 brand/app-icon.png 为选定资产。

## Global Constraints

- 用户已批准设计并要求实施；在用户指定的 feature-newUI-5 当前 checkout 工作，不重新询问设计方向或创建其他 worktree。
- 画布白 #FFFFFF，背景 #F3F5F9，正文 #182536，次要文本 #647184，主操作 #2859BC，警示 #B9413E；补齐深色语义色。
- 使用系统语义字体、20pt页面边距、至少44pt触点、50–52pt主要按钮、12pt控件圆角；平整列表和分隔线替代装饰卡片。
- 聊天收到白色、发送 #DCE7FD；发送气泡前景独立于实色按钮前景。保留状态标记和可访问性语义。
- 原生 TabView / NavigationStack / sheet / confirmationDialog 所有权及既有交互保持。设计稿的假状态栏、头像、文字、人数、二维码和媒体占位不得替换真实内容。
- 不修改 Network、SDK、Services、ViewModels、Models；不修改账号/权限/上传/会话/分页/已读/滚动时序；不恢复已暂停的列表返回偏移实验。
- 保留登录未勾选协议时弹确认、头像昵称编辑、资料正文备注编辑、投诉必填证据图、来电拒绝/接听和所有角色控制。
- 不修改未接入入口的 Original*、第三方依赖和工程签名。不要自动提交、推送或操作真实账号/真机。

## Review Focus

1. 深色：浅蓝气泡文字、语音、已读、引用、链接和选中描边仍可辨。
2. 大字体/窄屏：日期栏、身份行、分段筛选及底部操作不截断关键内容；可滚动。
3. 表单：密码显隐、焦点、验证码、保存禁用/提交和失败草稿保持。
4. 动态内容：真实昵称、计数、头像、搜索/空态/权限变化沿原绑定更新。
5. 导航与媒体：子页返回、确认取消、系统相册/扫码/通话/预览生命周期不变；不可用的设备证据明确标注。
