# 推送真机验收

客户端迁移与服务器APNs配置分开验收。本次没有读取cer目录、上传私钥、操作生产后台或向真实聊天发送测试消息。

当前工程Bundle ID为com.sigua.ddlNewapp；已有aps-environment=development和remote-notification由用户工作区提供，未由本次修改。签名后的实际aps环境与服务端topic/凭据必须匹配，不能用无签名build判断。

- [ ] 首次真实登录允许通知；Token先到/后到都能在服务器绑定当前用户。
- [ ] 拒绝权限后仍能登录；设置→通知设置展示系统状态并可打开系统设置。
- [ ] 前台收到普通消息仅提示一次；正在看的同一聊天静默；声音/震动开关分别生效，录音/通话时不抢占音频。
- [ ] 锁屏接收单聊、群聊、@本人/@所有人/@其他人、图片/语音/名片、群公告及好友申请。
- [ ] 会话免打扰、关闭群通知、总通知关闭分别按预期抑制；服务端APNs也遵循对应偏好。
- [ ] 点击通知进入正确会话/新朋友；冷启动等待真实登录，非法/无归属/未验证会话仅进入列表；检查处于设置/媒体弹层时点击的实际呈现。
- [ ] 同账号重新登录或更换账号/俱乐部后，旧回包与旧本地通知点击不跳入新会话。
- [ ] 退出解除推送绑定并清本机通知/角标；断网解绑失败的服务器状态另查，不宣称已清除服务器绑定。
- [ ] 杀进程状态由服务端APNs实际送达；验证生产签名包的正式环境。
- [ ] APNs与在线本地通知同时到达时检查重复展示；旧服务器payload没有共同消息ID，不能保证系统已显示的两条通知可由客户端事后合并。

不新增PushKit/CallKit或VoIP唤醒。后台系统通知的声音/震动受iOS设置控制。
