# 我的应用完整移植

用户确认完整移植 xgd 消息页「我的应用」，包含网页浮窗与恢复打开；沿用 ddlNew 的 SwiftUI、森林绿主题及真实 SDK。确认依据为本会话的完整功能清单与用户回复“完整移植”。

## 范围与方式
消息页增加默认收起的应用区域，展开后展示图标、名称、添加入口、管理/完成。服务端分页50条；刷新和失败重试，空态仍可添加。系统应用不可编辑，删除由 appType / allowUserDelete 决定。用户应用支持名称、HTTP(S)网址、图标、访问密码；需密码的应用先通过详情接口验证才能打开或编辑。删除前确认，失败保留列表和草稿。

采用现有 SDK MiniApp 接口与 SwiftUI 新页面；不拷贝旧 UIKit 页面及其全局窗口所有权。SDK 已有列表/新增/编辑/删除/详情/浮窗本地表，复用现有认证上下文、请求等待和图片运输。图标按旧端50KiB限制和 miniApp 目录处理，不生成消息。密码只在当前编辑/验证内存中存在。

网页使用 WKWebView，支持加载/失败重试、前进后退、关闭、复制链接、外部浏览器、浮窗。浮窗列表可恢复和移除；同一登录会话保留网页浏览状态，重启从 SDK 浮窗记录恢复地址。退出及换账号销毁网页与内存状态，不跨账号复用 Cookie/页面；受密码保护的记录恢复须重新验证。网页不注入账号凭据和原生业务桥。

## 视觉与交互
Operate 模式，扩展当前 MessagingTheme/UIAdapter。消息页顶部标题行“我的应用”和展开箭头；网格适配宽度，辅助字号改为易读列表。使用系统文字和 SF Symbols、真实应用图标，浅深色使用语义颜色。添加/编辑为表单 sheet；所有操作有44pt以上触点、无障碍名称，失败可重试且保留草稿。减少动态效果时不播放展开动画。网页沿系统导航，浮窗位于安全区，不遮挡底部 Tab。

## 比较
选择 SwiftUI 展示 + 现有 SDK 协议适配：保持新项目状态所有权，复用既有后端合同。直接搬旧 UIKit 会引入旧主题、全局窗口和控制器缓存；只迁移网页链接则遗漏用户已确认的管理、密码与浮窗能力。

## 验证
离线检查覆盖分页重试/去重、混合字段、删除权限、受密码保护的打开、保存失败保稿、旧认证迟到回包和浮窗恢复隔离。workspace 无签名 generic iOS 构建。可运行的匿名展示宿主用于浅深色、小屏/大字号视觉检查；真机与服务端验收单独列明，不自动操作真实应用数据。
