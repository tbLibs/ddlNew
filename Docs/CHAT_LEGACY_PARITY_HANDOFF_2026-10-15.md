# 聊天模块旧端对照与修复交接（2026-10-15）

## 范围与结论

本轮在 `feature-message-4` 上，以旧项目 `/Users/taobotaobo/Desktop/xgd` 的 Objective-C 聊天实现对照新项目聊天与群聊模块，覆盖入口、发送、消息操作、转发、定位、群管理、权限和多媒体 UI。当前改动修复了几处能由旧端源码及新端执行路径共同确认的差异。源文件之外的改动均保留；没有提交或推送。

## 本轮修复

- 文字、图片、视频、文件、语音等统一以 SDK `.ack` 且服务端消息 ID 非空作为发送成功边界。聊天视图等待最新消息布局完成后滚至底部；失败、上传完成和仅入队均不触发成功滚动。
- 当前会话逐条转发的服务端回执记录可触发同一成功滚动。合并转发继续等待 SDK ACK；其当前聊天 Store 是否收到实际 ACK，需后端运行时复验。
- 发送中、失败和无服务端 ID 的消息删除改为仅本地删除；不会用空 `sMsgId` 请求服务器删除。
- 删除菜单的单向删除权限沿旧端使用 `deleteMessage || remoteDeleteMessage`；双方删除仍单独要求 `remoteDeleteMessage`。
- 群管理员/群主本人消息撤回仅要求全局撤回开关开启，不受普通成员的撤回分钟窗口限制；普通群成员本人仍受窗口限制。管理员撤回他人仍受原角色和目标角色校验。
