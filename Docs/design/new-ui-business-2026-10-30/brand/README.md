## 启动行为边界

系统启动页只使用静态品牌画面。进入App后，等待界面保持背景及标志位置，仅提出无百分比的等待反馈。现有 LaunchWaitingView 直接复用 storyboard；这项等待反馈属于待确认的UI实现，而不是声称当前代码已有。保持 AppStartupCoordinator 原有恢复结果：无入口/连接失败进邀请码，连接成功但未恢复认证进登录，恢复成功进主界面。不得为展示品牌强制延时，不添加假百分比、倒计时或广告。
