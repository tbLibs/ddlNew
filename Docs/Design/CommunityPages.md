# 消息与通讯录

采用 ui-ux-pro-max 技能的可读层级、原生交互语义、44 pt 点击区域和搜索/空状态原则。检索产生的通用营销页配色与布局不适合当前 App，最终视觉以已有 ClubTheme 为准，不引入另一套配色或字体。

- 维持浅色：暖白背景、奶白卡片、深青绿文字、薄荷绿强调，沿用 17–22 pt 圆角与 20 pt 页面边距。
- 消息：标题和未读摘要 → 搜索 → 全部/未读/通知筛选 → 消息列表。行内包括图标、标题、时间、摘要与未读标记。点击消息行推入聊天页面并标记已读，支持全部已读，系统底部角标同步。
- 通讯录：标题 → 伙伴数量卡 → 搜索 → 全部/领队/常用筛选 → 按姓名拼音首字母分组。点击人员直接进入一对一聊天；同一成员使用稳定会话标识，重复进入不会创建重复消息列表项。聊天页右上角可查看成员资料、添加或移出常用联系人。头像使用文字色块，角色与兴趣提供识别线索。
- 消息、聊天与通讯录使用本地示例数据；不访问系统通讯录、不发网络消息。已读、聊天消息、输入草稿和常用联系人状态保留于本次会员会话，重启后恢复示例初始状态。
- 底部使用系统 TabView，包含首页、活动、消息、通讯录、俱乐部和我的六个页面。每个标签有独立 NavigationView；系统负责标签布局、未读角标、溢出到“更多”的导航和 iOS 26+ Liquid Glass 外观。不叠加自绘背景或自绘标签按钮。
- 新增消息/通讯录线性图标是本次绘制，源文件放在 Docs/FigmaAssets/Icons 便于统一维护，并非原 Figma 导出；Assets 内各提供 2x/3x PNG。其他原设计素材保持不变。
- 兼容项目 iOS 15 下限，沿用 NavigationView、FocusState 和已有 SwiftUIX/SwiftUI Introspect 能力。

聊天页使用原生返回导航、收发消息气泡、时间、头像及底部文字输入框；支持本地发送、过滤空白消息、自动滚动到最新内容、收起键盘和按会话保留草稿。发送后会话移到列表顶部，并更新摘要与时间。未读筛选下使用独立稳定的导航入口，打开消息后即使该行移出筛选列表，也不会退出聊天。

验证：iPhone 12 / iOS 26.5 三条 UI 测试通过，覆盖六个入口、未读数、全部已读、消息详情、搜索空状态、领队筛选、常用联系人以及原有报名/签到/键盘流程；iPhone 18 Pro / iOS 27 在最大辅助功能字号下的新页面交互测试通过，筛选项可横向滚动。真机签名构建通过。
