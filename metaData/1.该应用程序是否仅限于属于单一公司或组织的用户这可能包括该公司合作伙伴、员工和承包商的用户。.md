# App Store 使用范围审核问答（待最终构建及运营确认）

1. 应用是否仅限单一公司或组织的用户？

   当前代码没有组织成员资格或个人邀请校验。输入固定连接码 `100001` 即进入本地登录流程；这只能证明本地体验没有邀请门槛，不能证明生产服务面向公众开放。正式目标用户范围和发行方式待运营方确认。

2. 应用是否为特定或有限组织设计？任何组织都能成为客户吗？

   界面和预置内容以“远山户外俱乐部”为场景。当前仅有一个固定连接码，未发现远程组织查询或客户开通流程，不能据此承诺任何公司或组织均可成为在线客户。

3. 哪些功能面向公众开放？

   知道连接码的使用者可进入本地体验并自行创建本地账号，无需个人邀请或人工审批。活动、通讯录及消息界面的存在不构成真实公众在线服务的证据。公众能否发现、下载并使用最终发行版本及其生产功能，仍需最终安装包和生产环境验证。

4. 用户如何获取账号？

   输入连接码 `100001` → 点击“进入本地体验” → “注册本地账号” → 设置账号和密码 → 返回登录页手动登录，并按界面要求确认协议。`registerAccount` 将凭据写入本设备 Keychain，将账号及会话状态写入本地 WCDB；未发现远程注册请求。当前仅保留一个本地注册账号，再次注册会替换原凭据；不支持由此推断跨设备登录、服务端唯一性或真实多用户账号服务。

   也可使用预置示例账号，具体见 [审核访问步骤](zh-Hans.md#审核账号与备注)。示例账号不是生产会员身份或在线服务凭证。

5. 是否有付费内容？

   所检查的本地连接、注册和登录流程没有支付步骤。生产服务的收费安排及最终构建是否包含付费内容，须由运营方核实后再填写审核答复。
