How this relates to the review findings
Remote lookup: DNS1 obtains backend endpoints associated with the invitation code. The remote values can
change which server the app connects to.
Decoding: AAAA records carry fragments of a custom endpoint-list protocol. The fallback BIN carries encrypted
endpoint JSON. This is more than ordinary hostname resolution. The parsed values supply TCP connections
and optional API/file-transfer URLs.
Lookup credentials: DNS1DoHClient uses an account identifier, access key and a locally calculated signature to
authenticate the DNS-service request. The secret value is not sent as a plaintext query parameter. It is distinct
from the test user password.
Evidence boundary
This was a macOS command-line capture using current project functions, not a capture from the submitted IPA. It does not verify
user login, messaging, ECDH reachability or device reconnection. The next pages contain actual normalized results with explicitly
substituted addresses and ports.

Method and provenance
Capture procedure
1. Read the user-supplied review invitation code without saving it to a source file. Use DNS1DoHClient.records
for the live main-domain query and DNS1Payload.records for production parsing.
2. Request the configured BIN separately over HTTPS and pass its bytes to DNS1Payload.bin and
AesEncryptUtils. Compare the two unredacted TCP node sets in memory.
3. Inspect the original decoded formats in memory and cross-check the inspection output against the production
parser. Apply deterministic per-capture redaction, then save normalized JSON. Raw payloads and the mapping
are not retained.
The independent BIN request demonstrates the backup data source can return parseable data at capture time. It
does not demonstrate that the app automatically fell back from DNS during this run.

What these results do and do not establish
This capture confirms that the selected live DNS/BIN responses decode to endpoint data. The current DNS1 parser consumes
tcp/http endpoint fields and ignores unknown JSON fields. An absence of other fields in one sample is not a guarantee about future
responses or all app components. No app-account login, message transmission, node probing, device reconnection or App Store
submission was performed.
